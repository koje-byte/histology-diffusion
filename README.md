#  Targeted Diffusion-Based Synthetic Augmentation for Histological Imaging

**Deep Learning Capstone:** Evaluating the computational ROI of diffusion-based augmentation. An analysis of inference time complexity versus downstream classification impact in histological imaging.

##  Project Overview
This repository contains the generative data-engineering pipeline for enhancing histological image classification. By training diffusion models on specific, underperforming tissue classes, we generated highly targeted synthetic data to resolve class boundary failures.

###  Dataset & Compute Environment
* **Dataset:** [NCT-CRC-HE-100K](https://www.kaggle.com/datasets/imrankhan77/nct-crc-he-100k) (89,000 histological images).
* **Environment:** All models were trained and evaluated in the cloud using Kaggle GPU P100 accelerators. 
* *Note: Due to the massive scale of the dataset (89k+ high-resolution images), raw `.tif` files and heavy `.keras` weights are not hosted in this repository. To run this code, please mount the Kaggle dataset directly to your notebook environment.*

---

##  Targeted Generation Strategy (Hard Example Mining)
Rather than employing naive data-balancing—which risks introducing synthetic noise to stable classes—diffusion models were trained exclusively on three mathematically vulnerable classes to stabilize the dataset hierarchy up to a ~14,000 image ceiling:
* **STR (Stroma):** +3,000 images to break severe confusion boundaries with Muscle tissue.
* **NORM (Normal):** +2,237 images to act as a defensive mathematical buffer against Tumor false negatives.
* **MUC (Mucus):** +2,104 images to safely elevate the minority class and prevent volume deficits.

##  1. Generative Quality: Kernel Inception Distance (KID)
To ensure the synthetic images converged with real biological textures, KID scores were tracked across the final training epochs. A lower KID indicates higher feature-space similarity to real tissue samples.

## ⏱️ 2. Systems Evaluation: Time & Compute Complexity
Generative AI introduces a significant computational bottleneck. This project evaluated the exact time complexity required for histological data augmentation to weigh the compute cost against classification ROI.

* **Standardized Training Cost:** ~3.49 seconds per image.

## 🚀 3. Impact on Downstream Classification
The generated diffusion data was fed into a ResNet50 classifier. The targeted synthetic data created a symbiotic ripple effect across the network architecture:

* **Overall Accuracy:** Increased to **96.6%** from 96.0%.
* **Error Reduction:** Achieved a **15% relative reduction** in total classification errors.
* **Clinical Impact:** Successfully resolved the Stroma/Muscle boundary confusion and increased Tumor recall to 97%, eliminating critical false-negative classifications.
